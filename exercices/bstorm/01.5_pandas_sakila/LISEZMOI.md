# Exercice Sakila — informations pratiques

- **Énoncé** : `pandas_sakila.ipynb` (14 questions). Dans le fichier source, la numérotation de la liste est incohérente (1, 1, 1, 2…) ; affichée dans Jupyter, la liste est numérotée automatiquement de 1 à 14. C'est cette numérotation qui sert de référence dans le cours.
- **Données** : `data/sakila.xlsx` (aussi dans `donnees/bstorm/sakila.xlsx`). Chaque feuille contient une colonne `Unnamed: 0`, un ancien index exporté par erreur : à supprimer.
- **Version SQL** : l'approfondissement A3 charge ces tables dans PostgreSQL pour la partie « Bonus : comparez avec des requêtes SQL ».
