# D01 World Food Facts — Découvrir un jeu de données

- **Énoncé d'origine** : `exercices/drills/originaux/01_Getting_&_Knowing_Your_Data/World Food Facts/`
- **Données locales** : non fournie (téléchargement Kaggle manuel, environ 1 Go)
- **Place dans le cours** : Annexe

Le chemin d'un fichier local se donne relativement au notebook. Depuis le dossier de l'exercice, la racine du projet est cinq niveaux plus haut, par exemple `../../../../../donnees/drills/`.

## Étapes

1. Aller sur la page Kaggle « world-food-facts ».
2. Télécharger le jeu de données et le décompresser.
3. Lire le fichier TSV dans un DataFrame nommé `food`.
4. Afficher les 5 premières lignes.
5. Quel est le nombre d'observations ?
6. Quel est le nombre de colonnes ?
7. Afficher le nom de toutes les colonnes.
8. Quel est le nom de la 105e colonne ?
9. Quel est le type des valeurs de la 105e colonne ?
10. Comment le jeu de données est-il indexé ?
11. Quel est le nom du produit de la 19e observation ?

## Remarques

- Cet exercice demande un compte Kaggle et un téléchargement volumineux. Il reprend les mêmes notions que Chipotle et Occupation : il est placé en annexe.
