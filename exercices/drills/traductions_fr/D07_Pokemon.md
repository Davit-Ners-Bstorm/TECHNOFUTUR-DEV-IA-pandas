# D07 Pokemon — Créer des Series et des DataFrame

- **Énoncé d'origine** : `exercices/drills/originaux/07_Creating_Series_and_DataFrames/Pokemon/`
- **Données locales** : données créées dans le notebook
- **Place dans le cours** : Chapitre 2

Le chemin d'un fichier local se donne relativement au notebook. Depuis le dossier de l'exercice, la racine du projet est cinq niveaux plus haut, par exemple `../../../../../donnees/drills/`.

## Étapes

1. Importer les bibliothèques nécessaires.
2. Créer un dictionnaire de données.
3. L'affecter à une variable nommée `pokemon`.
4. Les colonnes semblent être dans l'ordre alphabétique. Les réordonner : `name`, `type`, `hp`, `evolution`, `pokedex`.
5. Ajouter une colonne `place`, avec les valeurs de votre choix.
6. Afficher le type de chaque colonne.
7. Bonus : formuler votre propre question et y répondre.

## Remarques

- L'étape 4 suppose un tri alphabétique automatique des colonnes : ce n'est plus vrai depuis Python 3.7. L'exercice de réordonnancement reste valable.
